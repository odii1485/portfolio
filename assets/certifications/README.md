listed below. Until a file is present, the site falls back to the stylised SVG badge
that ships with the page — so you can ship missing files as PNGs roll in.

### Where to download

- **Salesforce certs** → Credly: https://www.credly.com/users/rahul-odedra → open badge → Share → Download (PNG, transparent bg)
- **ISTQB** → save the badge from your LinkedIn certifications, or ISTQB/GASQ certificate portal

- **Shopify Solution Planning** → Shopify Partners → Academy → your certificate → download badge

## How to download from Credly (fastest path for the Salesforce ones)

1. Go to https://www.credly.com/users/rahul-odedra (or sign in at credly.com)
2. Open the credential
3. Click **Share** → **Download**
4. Choose **PNG** with transparent background
5. Rename to the filename in the table above
6. Drop it into this folder

## How to download from Trailhead (alternative for Salesforce certs)

1. Go to https://trailblazer.me/id and sign in
2. Click your profile → **Credentials**
3. Each credential has a "Verify" badge image — right-click → **Save image as…**
4. Rename to the filename above and place here

## File format guidance

- **PNG with transparent background** is ideal (badge sits cleanly on the dark card).
- Square or near-square ratio works best (~512 × 512 or larger).
- Filesize: aim for under ~150 KB per badge after compression.
  Use https://tinypng.com if files are large.

## What happens if a file is missing?

The card automatically shows a hand-drawn SVG fallback in the official badge's visual
family. No broken-image icon, no layout shift. Add the PNGs at your own pace.
